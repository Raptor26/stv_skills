# Анализ изменений

Проведи анализ незафиксированных изменений с помощью `git diff`.
Изменения необходимо сгруппировать по библиотекам, затем по областям изменений так, чтобы каждый из созданных коммитов можно было откатить в будущем с помощью git revert без поломок сборки, тестов и функциональности приложения.

# Пошаговый порядок

1. Первая группа изменений добавляется в git stage, сообщение фиксации формируется с помощью skill `git-committing-russian`.
2. Если в `git diff` еще остались незафиксированные изменения — вернись к шагу 1.
